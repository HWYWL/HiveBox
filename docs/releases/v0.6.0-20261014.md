# 🍊 HiveBox 固件更新啦！`v0.6.0-20261014`

这一版主要是**提速**：满屏刷新的墙钟时间从 **44.6 ms 压到 20.3 ms**，几乎快了一倍 ⚡ 而且不是靠调参调出来的 —— 是**每帧少做了一次整屏拷贝**。

顺手还给任务查看器加了一列 **「占用率」** 📊 现在能看到每个任务吃了多少 CPU、以及**两个核各还剩多少** —— 上一版把界面搬到 CPU1 时，「另一个核是空的」这句话还只能靠估，现在它是一行读数。

---

## ✨ 这次更新了什么

### ⚡ 每一帧都省掉了一次整屏拷贝

- 原来每送一次显，都要先把画面**整屏拷进一块 PSRAM 影子帧**，再从影子帧切条带、换字节序、发给屏。满屏一次 flush 是 **44.6 ms**，其中**光这次拷贝就吃掉 20.9 ms** —— 快一半的时间，花在「把刚画好的东西原样搬到另一个地方」上
- 现在**影子帧没有了**：送显直接读合成器自己那块帧缓冲 🎯 满屏 flush 从 44.6 ms 掉到 **23.7 ms**
- 一起去掉的还有那块**半兆的 PSRAM**。内部内存本来就紧，这一块不小

### 🔁 字节交换内核：别让它一个一个字地等

- 屏要的是大端 RGB565，板子上是小端，所以每个像素都得把两个字节换个位置。原来的循环是「读一个字、换、写回」—— **读写串着走，同一时刻只有一个读在飞**，PSRAM 每次读那十几个周期全白等
- 改成**先连着读四个字、再一起写回**，让几个读同时在途。同一个内核、同一批字节：**31.8 MB/s → 38.8 MB/s**，满屏这一段从 18.76 ms 降到 **16.68 ms** ✅
- 顺手量了件反直觉的事：**展开到八个字反而更慢**（掉到 21.8 MB/s）。Xtensa 只有 16 个通用寄存器，八个字加两个指针就放不下，值被**溢出到栈上** —— 多出来的访存比省下的等待还贵。四个字正好是寄存器装得下的宽度，这个数写进注释了，省得以后有人再试一遍
- 还量了另一件事：**这个跨步访问其实不花钱**。竖切条带时，每行是从 480 宽的画面里抠 32 个像素、下一行跳 960 字节 —— 听着很伤缓存，实测和「老老实实按地址顺序读」只差 **7%**。所以慢跟访问顺序无关

### 🚀 QSPI 时钟 60 → 80 MHz

- 整屏 460.8 KB 的传输时间从 **15.3 ms 降到 11.5 ms**，80 MHz 是这颗芯片 SPI 主机的上限
- ⚠️ 如果刷完出现**杂点或断列**，就是这一项：板间有差异，把 `sdkconfig.defaults` 里这一行注释掉、退回 60 MHz 重编即可

### 📊 任务查看器多了「占用率」一列

- 每个任务现在会显示自己吃了**多少 CPU**（一位小数）📈
- **`IDLE0` 和 `IDLE1` 这两行是关键**：空闲任务是「这个核没别的事可做时才跑的那个」，所以它的占用率**就是那个核还剩多少**。两个核还有多少余量，一眼看完
- **没有这个计数器的板子，这一列画 `-`**，而不是画个 0 —— 0 会被读成「这个任务什么都没干」，那是两回事
- 代价说清楚：**每次任务切换都要多读一次计数器**，而这块板子每秒切换几千次 🫠 它是个「看着它时开着、不看了就关」的旋钮，源码里写明了
- 桌面模拟端也有这一列，占用率**随时间增长**、加权求和正好 100

### 🧵 界面主任务搬到 CPU1

- 之前界面和 **Wi-Fi、TCP/IP 挤在 CPU0**：一帧还没画完，一包网络数据就插进来 🧨 现在**电台留在 CPU0，面板独占 CPU1**
- 敢这么搬，是因为**另一个核本来就是空的** —— `IDLE1` 常年在 99.9%。这句话上一版只能估，现在任务页里就能看到

### 🔤 字体补了一个字

- 加了 **「雲」**（U+96F2，`云` 的繁体）。字表 4012 → **4013** 个字，24 px 那张表大约多 **506 B** —— 一个字就是这么点重量

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.6.0-20261014.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xABFF00`，而数据分区从 `0xB00000` 才开始 —— 你的 **Wi-Fi 密码、音乐设置、服务器列表和文件都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

## 🏷️ 版本号怎么读

`v` **0** `.` **6** `.` **0** `-` **20261014**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `6` | 功能版本 | 加了新功能 |
| `0` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261014` | 构建日期 | 这一版固件是哪天编译的 |

这一版**板子上的应用变了**（任务页多出一列占用率），所以动的是第二位，第三位归零 🫶
