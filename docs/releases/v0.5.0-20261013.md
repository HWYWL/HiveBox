# 🍊 HiveBox 固件更新啦！`v0.5.0-20261013`

「游戏」里来了**第二款** —— 贪吃蛇 🐍 而且这一次 **板子自己就是手柄**：把机身往哪边压低，蛇就往哪边走。

这一版还顺手做了一件安静但挺影响体验的事：**界面字号从「四档可调」收敛成一档** 🔤 省出来的空间全给了你能写的那一半 —— **数据分区从 3 MB 变成 5 MB** 💾

最先说清楚代价：**数据分区上的东西照旧不动** —— Wi-Fi 密码、音乐设置、配好的服务器列表、你自己放上去的文件都还在 🎵 刷机命令一个字都没改。

## ✨ 这次更新了什么

### 🐍 新游戏「贪吃蛇」：一款会自己动的游戏

- **16×16 的格子**，吃到苹果长一节，撞墙或撞到自己这一局就结束。上一次的 2048 是「你不碰它它就不动」，这一个刚好相反 —— 它会自己往前走，你要做的是**别让它撞上**
- 它会**越吃越快**：每步从 **220 ms** 起，每吃一个苹果少 **7 ms**，最快到 **90 ms** 为止。不加速就只是一局越玩越长的游戏，没有下限则还没看清就已经结束了
- 它和 2048 用的是**同一张 304 px 的棋盘**（16 格 × 19 px，格子之间不留缝 —— 蛇是一具身体，不是一列方块）。所以换游戏的时候换的是**玩法**，不是版面 🎯
- 开局种子照旧是**板子的开机时长**，所以每次打开都是新的一局，棋盘不可能和上一局一样

### 📐 拿起板子就是手柄：倾斜机身转向

- **把哪一边压低，蛇就往哪边走** —— 读的是加速度计里那点方向分量，阈值约 **20°**（重力在那一轴上的 0.35）。比手抖大得多，又不用把板子竖起来
- **平放就是不转** ✅ 这一条很关键：用方向键玩的人，不会被「上一次的倾斜」一直带着走 —— 读不到倾斜就是「没有意见」，而不是「保持上次那一边」
- 判断是先**除以读数自己的模长**再看方向的，所以驱动报 g 还是 m/s² 都不影响：它比的是「重力的几分之一」，不是某个单位下的数字
- 这个读数**只在一局蛇开着的时候读**。2048 不碰它 —— 那个游戏是有人动它才动，为一张不变的棋盘每秒重画六十次没有意义；反过来，蛇一结束，时钟也就停了 🕐

### 🔤 界面字号：四档变一档，省下 2.6 MB 的 flash

- 设置里原来能选 **18 / 20 / 24 / 30 px** 四档。但每一页的每一个尺寸本来都是从**同一个基准**推出来的 —— 四档只是让同一张页面在四个大小之间缩放，不是四种设计
- 现在基准就是**一个数**（`FONT_BASE`，24 px），设置 → 主题页里那一行**删掉了**（不是藏起来，是真的没有可选项了）
- 跟着删掉的是 **18 px 与 20 px 两套预烘字形表**（在构建机上先把字形光栅成位图，设备查表命中就不用在板上现画）。它们是按字号逐位比对命中的，**同一时刻只有被选中的那一档会命中** —— 另外两张表一直躺在 flash 里，没有任何代码会读到 📦
- 顺带把终端自己那套写死的 18 / 20 / 30 px 常量也删了：字与行高改从同一个基准推，行高按 1.3 的同一个比例算 —— 一格比自己的行盒还矮，会把字顶切掉

### 💾 省下来的空间给了「你能写的那一半」

- 应用分区原来为了装下三张表开到 **12 MB**，现在收窄到 **10.94 MB**（固件本身 9.08 MB，还留约 1.9 MB 余量）
- 加上芯片尾部原本**闲置的 0.94 MB**，一共 2 MB 全部并给数据分区：**`internal` 从 3 MB 变成 5 MB**，可写空间多了 67% 🎉
- 整张 **16 MB 的 flash 现在一点不剩** —— 分区表最后一行刚好顶到芯片末尾。概览里那张存储图在桌面上也与板子上显示一致了

### 🧹 顺手扫掉的

- **设置里的「字号」一行没了**（理由见上）
- **各页的自检从「四种字号 × 两种语言」变成「一种字号 × 两种语言」** —— 原来是在四倍的工作量里找同一个错，现在一次就够
- **桌面模拟端的 flash 布局跟着分区表一起改**，卡片的读数与板子上对得上
- **一批没跟着更新的旧数字**：设置页的文档、分段条的单测和 HAL 的布局单测里还留着 `0xC00000` / `0x300000` / `0xF0000` 那套旧分区，存储页的集成测试更是直接断言起「芯片尾部还有 0.94 MB 没分配」——**这条测试是红的**，也就说明这次改动之前，整套测试从没被完整跑过一遍 🫠 现在全按新表算，顺带让「零字节的区段也必须拿到一份（否则布局引擎会把整条 bar 都发给它）」这条规则，因为尾段真的变成 0 而第一次被真正测到 ✅

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.5.0-20261013.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0x8E0000`，而数据分区从 `0xB00000` 才开始 —— 你的 **Wi-Fi 密码、音乐设置、服务器列表和文件都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

## 🏷️ 版本号怎么读

`v` **0** `.` **5** `.` **0** `-` **20261013**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `5` | 功能版本 | 加了新功能 |
| `0` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261013` | 构建日期 | 这一版固件是哪天编译的 |

这一版**加了第二款游戏**（多出了一种操作方式：倾斜机身），是功能版本，所以动的是第二位，第三位归零 🫶
