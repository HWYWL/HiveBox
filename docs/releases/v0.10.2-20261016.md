# 🍊 HiveBox 固件更新啦！

> **版本**：`v0.10.2-20261016`　**芯片**：ESP32-S3　**合并镜像**：`hivebox-firmware-v0.10.2-20261016.bin`（5.78 MiB / 写入偏移 `0x0`）

这一版把**「板子自己刷固件」**接通了：更新页的「**固件**」那一行点一次「**安装**」，板子自己把新固件从仓库下下来、写进**另一个**固件槽，装完点一下「**立即重启**」，跑的就是新固件了 —— 不用再插数据线。⚡

顺带给固件更新加了一道防线：**写坏的固件会自己退回去**。🧯

---

## 📥 更新页的「固件」那一行，点「安装」就行

和「字库」那一行是同一套手感：

- **进度条会走**：百分比 + `1.2 MB / 5.7 MB` —— 那几个数字回答的是「它到底动没动」，那是等人时唯一能看出没死的东西 ⏳
- **可以取消**：下到一半不想装了，按「取消」就行 🛑
- **中断了不留半截**：拔电、断网、点了取消 —— 那个槽都不会变成「可以启动」的。写进去的字节只有整个请求完整下完、写完、被 `esp_ota_end` 收下，槽才算数 🛟
- **装完会问一句「要不要重启」**：和字库一样，「**稍后**」与「**立即重启**」两个按钮 🔁

## 🧯 写坏的固件会自己退回去

板子上有**两个**固件槽，本来就是为这一刻准备的：新的写进闲着的那个，写坏了还有原来那份在。这一版之前，那只是前半句 —— 新固件起不来，板子就停在那儿。现在两半都成了：

- 新固件写完是**待验证**状态，bootloader 会启动它，但**留着退路** 🔍
- 只有它自己说一声「我起来了」才算站稳。这一声在**第一帧画到屏上**那一刻说 —— 到那一刻为止，一次更新能弄坏的东西都跑过一遍了：板子起来了、字库在它该在的地方、渲染器画得出、屏把这一帧收下了 ✅
- 在那之前崩了、卡住起不来，下次复位 bootloader 就把**原来那份**装回来 🧯

所以：**更新失败不会把板子变成砖**。

## 🧾 发布面现在是两份固件，清单指的是新那一份

`bin/` 里从此躺着两份镜像，名字不同、用途也不同：

| 文件 | 是什么 | 谁用 |
| :--- | :--- | :--- |
| `hivebox-firmware-*.bin` | **合并镜像**：bootloader + 分区表 + 应用，首尾相接 | 用**数据线**刷机的人（写 `0x0`） |
| `hivebox-ota-*.bin` | **应用镜像**：一个固件槽的内容 | **板子自己**在更新页里下 |

`manifest.json` 里 `firmware.file` 指的就是后面那一份 —— 在线更新做的正是「把一份镜像写进一个槽」，而槽里放的从来不是一整片 flash 的开头。把合并镜像塞进去，`esp_ota_end` 会拒收，而那时槽已经被写过了 🚫

## 🚧 还没有的东西（先说清楚）

- **没有「回退」这个按钮**：回滚只在「新固件起不来」时自动发生。新固件起来了、只是你更喜欢旧的那份 —— 这一版没法退，还是得插线 🚧
- 固件更新**不跨大版本保平安**：清单只给一份最新固件，没有选版本下载的地方
- 装完固件**要重启**才生效，没有热切换
- 「字库」那一行照旧：字体是重启后生效的

## 📦 怎么刷

```bash
esptool.py --chip esp32s3 -p <你的串口> write_flash 0x0 hivebox-firmware-v0.10.2-20261016.bin
```

**这一版得用数据线刷一次**：回滚要用新的 bootloader，而 bootloader 只有数据线刷得进去。**分区表没动**，所以 Wi-Fi 密码、文件、服务器列表、SD 卡上的字体包都还在。刷完开机，更新页的「固件」那一行就能在板子上装了 —— 那一步不用再插线。

## 🏷 版本号怎么读

`v0.10.2-20261016`：`0` 大版本（第一位数）、`10` 这一版加了多少东西（第二位数）、`2` 修了多少问题（第三位数）、`20261016` 编译日期。
**这次动的是第三位** —— 这一版是把已经画出来的那一行接通、再补一道防线，没有新开一页、没有加磁贴。

## 🍊 刷完可以看看这几处

- 进「**更新**」→ 点「**检查**」：「**固件**」那一行会指出仓库里这一版 👀
- 点「**安装**」：进度条走起来，装完提示里多出一个「**立即重启**」📥
- 点「**立即重启**」：板子当场重启，进「**设置**」看「固件版本」已经变成新那一版 ✅
- 下载中途按「**取消**」再点「检查」：还是原来那份在跑，机器照旧 —— 槽没有被写坏 🛟
