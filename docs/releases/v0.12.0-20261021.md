# 🐋 HiveBox 固件更新啦！`v0.12.0-20261021`

这一版的关键词是**「账户看得见」** 👀

桌子上的小屏幕以前会告诉你电量和天气，现在它还会告诉你：**DeepSeek 账户里还剩多少钱、今天花了多少** 💸
而且不只是看一眼 —— 令牌、key、用量，全都能在网页上管起来。

---

## ✨ 这次更新了什么

### 🐋 新应用「DeepSeek」

启动器第二页，WorkBuddy 旁边，蓝色小鲸鱼 🐳

- **余额一张卡**：总余额放大加粗，充值 / 赠送分开列，右上角顺手带上累计消费
- **今日三项一张卡**：花了多少钱 / 请求几次 / 烧了多少 token —— 三个数一眼扫完
- **24 小时柱状图**：今天哪个小时最忙，一根一根柱子画出来 📊
  用的是接口本来就带的按小时分桶，**不多发一次请求**
- **右上角一个圆钮**：转一圈重新读，读的时候按钮是灰的
- 没有控制台令牌也不影响：**余额照给**，用量那半画破折号并说明去哪儿填

### 🔐 网页上终于能管凭据了

`http://<板子IP>/` → 顶部多了 **DeepSeek** 一页：

- **已保存**：两行，各自显示掩码（`sk-…4ab8` / `…yfMz`），各带「编辑 / 删除」
- **编辑**＝粘一枚新的覆盖旧的（板子从来不会把完整的交出来）
- **删除**＝只删这一枚，另一枚不动；两枚都删光，文件一起消失
- **保存并读取**：存完立刻读一次，逐条告诉你 —— 余额多少、key 能不能用、userToken 过没过期

还附了一份**怎么拿 userToken** 的四步教程（F12 → Application → Local Storage → `userToken`），
拿不到的时候照着点就行 👌

> 为什么不能「一键获取」：这页是板子在局域网上发出来的，跟 `platform.deepseek.com` 不同源，
> 浏览器不许它去读人家的 localStorage。给步骤是唯一诚实的做法 🙃

### 🖼 两个应用都戴上了自己的 logo

标题前面各一枚：DeepSeek 是蓝底白鲸，WorkBuddy 是绿底白色标记。

这块屏没有 PNG 解码器 —— 图是**构建时**就烘成 RGB565 + alpha 的静态数组，运行时直接铺，
不占一次解码、不占一次分配。

### 📊 WorkBuddy 也能看今天了

- 今日消耗积分 + 今日请求次数，从 `get-user-request-usage` 分页求和
- 界面重做：图标、剩余率进度带、今日一行
- 返回体里的**整段提示词已经被删掉** —— 这页在局域网上没口令，别人的对话不该出现在那儿

### 🐛 修掉的几个坑

- **「填了 userToken 却说过期」**：表单值没做 percent-decode，`+` 存成了 `%2B`。现在解码了
- **「假零」**：平台把拒绝放在 HTTP 200 里（`{"code":40003}`），原来被当成「读到了、数是 0」。
  现在先看 `code`，判成「这枚不作数了」
- **「点 DeepSeek 白屏」**：视图切换里有两份写死的页面清单，新页面不在里面。顺手修了
  「在 WorkBuddy 页刷新会跳回文件页」
- **「赠送显示 0.00」**：余额被平台摘要覆盖了，现在只认官方 `/user/balance`
- **「删除按钮会误删两枚」**：`?which=` 打错字原本会落回「两枚都清」，现在回 400
- **「字被圆角切掉」**：四边留安全区，按钮挪到右上角
- **`7,443,755` 放不下**：改成 `7.44M`

## 🚀 怎么升级

**在板子上直接升**：设置 → 更新 → 检查（这版改了应用，不建议跨版本乱跳）

**或者数据线刷**：解压后 `hivebox-firmware-v0.12.0-20261021.bin` 刷到 `0x0`，
OTA 那份 `hivebox-ota-v0.12.0-20261021.bin` 是给更新页自己下的 🙌

## 🏷 关于版本号

`v0.12.0-20261021`

- `0` 大版本，重大更新（这次没动）
- `12` 加了功能（DeepSeek 应用 + 网页凭据页）
- `0` 修 bug、优化
- `20261021` 编译日期

设置页里那行版本和这个 tag **一字不差** —— 它就是构建时的 `git describe` 🔍
