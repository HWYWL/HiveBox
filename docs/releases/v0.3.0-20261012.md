# 🍊 HiveBox 固件更新啦！`v0.3.0-20261012`

桌面从 **7 个应用变成 11 个** —— 两张桌面翻成三张，多了四个应用：**时钟**、**概览**、**文件管理**、**电量日志**。

最先说清楚代价：**`use_flash` 数据分区上的东西照旧不动** —— Wi-Fi 密码、音乐设置、配好的服务器列表都还在 🎵

---

## ✨ 这次更新了什么

### ⏰ 新应用「时钟」：一个表盘、一个番茄钟、一份闹钟

- 三个标签页装在一个磁贴里 —— 表盘（指针 + 日期）、番茄钟（一圈倒计时）、闹钟（列表）。**切页不会打断番茄钟**，这是用番茄钟的人最在意的一件事
- 番茄钟按**板子的开机时长**计时，不是按这个应用活了多久：退出应用再进来，剩下的时间还在走
- 板子的时钟**从没对过时**的时候，表盘不画指针、读数写 `--:--:--`。给一块不知道几点的板子画一个「12:00」，是在替它编一个事实
- 闹钟列表存在 `AppData/CLOCK/alarms.txt`，改一次存一次；铃声是开机时合成一次写下来的

### 📊 新应用「概览」：整台板子一屏看完

- 五张卡：**电量、无线网络、存储、内存、服务器** —— 想不起来是哪一项不对时，打开这一页就够
- 每秒刷新，但**慢的那两个问题不是每秒问一次**：卡槽里有没有卡是一次 SDMMC 事务，隔壁那台机器是一次 SSH 登录，它们只在你**打开这一页**和点右上角**「刷新」**时发起，答案在下一拍取回来（按钮上写着「正在检查」，因为屏幕上那几个数此刻确实还是旧的）
- 存储卡同时给出**内置分区**和**TF 卡**两行；内存卡分**内建堆**与 **PSRAM** 两个池子，不混着算

### 📁 新应用「文件管理」：内置分区与 TF 卡，两边都能动

- 上面一排**卷**（内置 / TF 卡），下面是当前目录；**一次点选、再点一次进入** —— 触屏没有双击可以借，这也是「选中但没进入」这个状态存在的理由：重命名要的正是它
- 四件事：**新建目录、重命名、删除、复制 / 粘贴**。删除与粘贴都先问一次
- 读文件系统走 `std::fs`（终端与音乐播放器一直这么读），**写走板子的存储后端** —— 见下面那一段

### 🔋 新应用「电量日志」：电量随时间是什么形状

- **放电曲线**：每分钟一个点，画最近 **120 分钟**，一列一个采样、柱高就是当时的电量
- **预计剩余时间**：按当前放电速度算，旁边同时写着那个速度 —— 只给答案不给依据，是在要求别人相信它而不是读它
- 充电中、或电量已经空、或曲线是平/上升的时候**不给估算**：估算是对「正在放电」这件事的陈述，没有放电就没有这个陈述
- **芯片过热警示条**盖在读数**上面**而不是塞进某张卡里：它是这一页唯一一条警告，藏在曲线下面的警告会被人划过去
- **每小时往 `AppData/POWER/history.csv` 追加一行**（追加，不是重写 —— 否则每加一行都要把它前面的每一行读回来再写回去，成本随文件变老而涨）。页面上有个「立即记录」，因为等一小时才知道盘有没有写成太久了
- 写盘失败**不静默**：哪一步错了写在日志卡上，没写成的行也不计入行数

### 🧱 存储层补上「写」这半边

- `pomelo-hal` 的 `StorageBackend` 新增 `write_file` / `append_file` / `remove_file` / `rename`
- 原因是这台板子上 **`std::fs` 能读、能 stat、能列目录、甚至能建目录，但建不了「文件」**：`File::create` 和每一种 `OpenOptions` 写法都返回 `ENOENT`（当初 Wi-Fi 凭据就是这么丢的）。所以写入统一走后端，C 侧用的是 `main.c` 一直在用的那个 `fopen`
- **跨卷改名**（内置 ↔ TF 卡）是「复制 + 删除」：两个驱动之间没有 inode 可搬 —— 复制没走完就把目标删掉，**目标的名字上永远不会留半截文件**；原文件只有在副本完整关闭之后才会删
- 网页控制台的「移动」**改用同一个实现**，不再是自己那份一次一 KB 的循环：同一件事写两遍，就是两个地方可以把半截文件这件事弄错

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.3.0-20261012.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAC0000`，你的 **Wi-Fi 密码、音乐设置和配好的服务器列表都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

`v` **0** `.` **3** `.` **0** `-` **20261012**
