# 🍊 HiveBox 固件更新啦！`v0.10.0-20261016`

这一版把上一版留下的那个**方框**收拾掉了 ⬜➡️✅ —— 上一版为了腾出第二个固件槽，把内置字形表从 4013 字裁到 528 字，代价是**源码里没写过的字画不出来**：SD 卡里的中文文件名、路由器的 Wi-Fi 名、服务器返回的中文，统统是一个方框。

现在补上了：**开机从 SD 卡读一对文件** —— 一份更全的字体，和照它烘出来的字形表。两个一起放进 `/sdcard/fonts`，重启即可，**不用重刷固件** 💾

同时，更新页的「**字库**」那一行**能在板子上装了** 📥

---

## ✨ 这次更新了什么

### 🔤 卡上的字体包：方框的解药

- 开机时去 SD 卡找**一对**文件：
  - 字体：`/sdcard/fonts/hivebox-face-*.otf`
  - 字形表：`/sdcard/fonts/hivebox-font-24px-*.bin`（两张名字里的版本号要对得上）
- **两个都读到才用它画字**，缺一个就退回内置那份 —— 半套东西不会把机器带进「画不出字」的状态 🔒
- 这一版的卡上字体包收 **GB2312 的全部可显字符 + 源码里画过的字**：符号、标点、全角字母、拼音、希腊字母、一级汉字 3755 字…… 24 px 的表 **4537 个字形、零缺字** ✅
- 字体 **1.91 MB** + 表 **2.27 MB**，读过一次就一直留在 PSRAM 里（8 MB 够放），不占 flash 一个字节 🧠

**怎么用**：把这两个文件拷进 SD 卡的 `fonts/` 目录（没有这个目录就建一个），重启。仓库里的位置是 `ui-framework/pomelo-font/dist/card/` 👇

```
SD 卡
└── fonts/
    ├── hivebox-face-v3.otf
    └── hivebox-font-24px-v3.bin
```

### 🧾 表靠哈希认领自己的字体

- 表头现在带着**烘它那份字体的 SHA-256**（前 16 字节），渲染器拿它和手里那份字体比对 —— 对不上就不认领 🧩
- 以前判的是「这是不是镜像里那一份」（指针比较），卡上来的表在那个判断里**没有归属**
- 于是有一条必须说清楚的规则：**换表救不了内置字体里没有的字** —— 表的字形号是那份字体的字形号，不是通用的，要多认识字就得**连字体一起换** 🔑
- 还有一条：**成套的包赢过更新的孤表**。孤表（只有表、没有配对字体）是照镜像里那份字体烘的，把它交给卡上的字体等于递过去另一套字形号，渲染器会拒收 —— 被拒之后每个字都要**现场光栅**（约 1.6 ms/字形）。所以这是**正确性规则，不是偏好** ⚖️
- 字体与表**各 3 MiB 上限**，超了就不装（不会把开机拖垮）

### 📥 更新页：「字库」那一行现在真能装了

- 点「安装」先问**卡在不在**（没有卡就直说，装不了），然后从仓库把表拉下来写进 `/sdcard/fonts` 💾
- **有进度**：百分比 + `84 KB / 228 KB` —— 两个数字都要，百分比回答「还要多久」，字节数回答「它到底动没动」，后者是等人时唯一能看出机器没死的东西 ⏳
- **可以取消**，中途退出不会留下半个可用的文件
- 写完**核对大小**：不对、或者拿回来的是一张网页，就把那个文件**删掉**。文件名就是开机认表的方式，留一个半截的在那儿，下次开机就会拿它去画字 🧹
- 进度来自一个新的 HAL 接口（`HttpProgress`），它**只在请求在飞时才有意义** —— 没有请求时读到的是上一次的余数，画出来就是一根已经走完的进度条

### 🚧 说清楚这一版的边界

- **「固件」那一行还是「这一步还没接通」** ⏳ 字库那行做的是「下载 + 写文件」，固件那行要的是「写进**另一个** OTA 槽 + 重启」，那是另一件事，这一版没做
- **这一页只能递交一个文件，所以它装不来「新字」**：它给的是一张照**镜像里那份字体**烘的表，换不掉字体本身 —— 要更多字（比如繁体、生僻字），把上面那个包拷到卡上（那是两个文件，讲得清是一对）🤝
- 仓库里那份字库表是 **v1**（234 KiB，就是镜像里那张）；卡上装了 v3 的包时，这一行会显示已经是最新 ✅

### 🈶 补了一个字：「雲」

- 卡上的字符集补了 **「雲」**（U+96F2，`云` 的繁体）—— GB2312 的一级汉字里只有简体「云」，繁体不在里面 🀄
- 这类字**没有批量来源**，只能一个一个显式列出来；顺手把生成这套字符集的脚本也写下来了（`tools/gen_charset_gb2312.py`）—— 以前是「文件生成了，但没说怎么生成」📜
- 重烘之后的卡上包：24 px 表 4536 → **4537** 个字形，**零缺字** ✅

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.10.0-20261016.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ **刷机方式没变**：分区表没有动，**Wi-Fi、服务器列表、内置存储里的文件都还在** 🔒
- ✅ 这份 app 镜像 **5.64 MiB**（下载到的合并镜像 **5.77 MiB**，多出来的是 bootloader、分区表与一份初始的 `otadata`），装在 6 MB 的 `ota_0`/`ota_1` 槽里，还剩 **374 KB（约 6%）** 📐
- ✅ **SD 卡上的东西一个都不动** 💾
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

**想告别方框的话再加一步**（可选、不用刷机）：把 `ui-framework/pomelo-font/dist/card/` 里的**两个文件**拷进 SD 卡的 `fonts/` 目录，重启 🔤

## 🏷️ 版本号怎么读

`v` **0** `.` **10** `.` **0** `-` **20261016**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `10` | 功能版本 | 加了新功能 |
| `0` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261016` | 构建日期 | 这一版固件是哪一天编译的 |

这一版**板子上多了一件能做到的事** —— 更新页的字库那一行能装了，另外卡上多了一种「字体包」可以放 —— 是**功能**版本，所以动的是第二位，第三位归零 🫶

设置 → 系统信息里的「**固件版本**」，显示的就是这个 tag —— 和 Releases 上完全对得上 ✅

## 🍊 刷完可以看看这几处

- 进「**更新**」→ 点「**检查**」：两行都填上版本号之后，看「**字库**」那一行 👀
  - 卡上有包 → 显示包的那个版本；卡上没有 → 「未安装」
  - 点「**安装**」：会有进度条走起来，走完提示已更新 📥
- 进「**文件**」：翻到 SD 卡里**中文名**的文件 —— 上一版这里是方框，现在应该是字了 ✅
- 进「**设置 → Wi-Fi**」：名字里有中文/繁体（比如带「雲」字的）的 AP，现在也画得出来 📶
- 进「**设置 → 存储**」：卡上的空间会少了 4.2 MB —— 那是字体包 🗺
