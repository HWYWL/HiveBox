## ✨ 这次更新了什么

### 🛰️ 服务器监控：从「画得出来」到「真的连上」

- 板子里的 SSH 换成 **Rust 写的**（`sunset`），原来那套 C 库（libssh + mbedTLS）整条链路去掉，镜像里不再有 C 的 SSH 代码
- 迁移路上撞到两个会真正让功能失灵的问题，都修掉了：会话线程 32 KB 的栈在内部内存里已经挤不出来（改从 PSRAM 拿）；而这块芯片**不允许栈在 PSRAM 的任务碰 flash**，连读都不行，于是主机密钥的读写全部搬出会话线程
- **点开一台机器，CPU 与网络大约五秒就有数**（原来要十几秒）：一台机器的第一次读取在同一个连接里连着采两次，第二次采样不用再登录一遍

### 🗂️ 多台设备

- 进应用先看到**设备列表**：每行一个地址、一个账号，外加**在线 / 离线**
- **在线 / 离线是现在时**：板子自己去敲每台机器的 SSH 端口（只开一个 socket，不登录、不开会话），列表开着时每十秒过一轮 —— 不再是「多少秒前」
- 底部**直接在板子上添加设备**：地址、账号、密码三个字段配面板键盘；同一地址再存一次是**更正**而不是新增
- 监控页右上角可以编辑，表单里可以删除；网页管理页的表单改成**追加**（填一台加一台），「停止监控」相应改成「清空监控列表」

### 🔧 顺手修掉的几处

- **硬盘表**：盘名与型号放不下就按列宽截断，不再换行、不再和容量那一列互相压住
- **读不到数时画的是短横**：CPU、网络、内存、存储、磁盘繁忙在「还不知道」时不再画一个空方框（面板字体里没有那个破折号）
- **「固件版本」真的只剩版本号了**：以前会显示成一长串 `v0.1.1-20261010-16-gf7c258c-dir`
- **运行时间不再被屏幕圆角切掉**；概览从四张卡变六张（多了「存储」与「磁盘繁忙」）；「硬盘」选项卡点得动了

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.2.0-20261012.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAC0000`，你的 **Wi-Fi 密码、音乐设置和配好的服务器列表都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

## 🏷️ 版本号怎么读

`v` **0** `.` **2** `.` **0** `-` **20261012**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `2` | 功能版本 | 加了新功能 |
| `0` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261012` | 构建日期 | 这一版固件是哪天编译的 |

这一版既有新功能（真实 SSH 会话、多台设备）也有若干修复，所以功能位 +1 🫶
