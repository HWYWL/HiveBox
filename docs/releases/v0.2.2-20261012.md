# 🍊 HiveBox 固件更新啦！`v0.2.2-20261012`

这一版全部在**网页管理页**上 —— 用手机或电脑打开板子那个页面，少点几下、少看几眼空白。

先说重点：**画面镜像不再被裁掉**，而且**点过之后画面会自己更新** —— 原来终端已经执行了，网页还停在旧画面。

---

## ✨ 这次更新了什么

### 🖥️ 画面镜像：完整，而且会跟着走

- 镜像是**按卡片宽度放大**的（480 的方屏拉成 688），而外框的高度有上限，于是**底部被裁掉** —— 屏幕上最下面那一排按钮正好藏在「截屏 / 熄屏 / 响一声」后面
- 现在按「装得下」定尺寸：宽度与那个高度上限两者取小，任何窗口比例都完整可见（实测 819×780、1440×900、390×844、1024×620 四种比例都不裁切）
- 在镜像上**点按或拖动之后，画面自己取一张新的**（松手约半秒后），并且新画面到位之前旧画面不收走 —— 不会每点一下都闪一次「正在取回屏幕…」
- 触摸换算本来就是按信箱式算的（`scale` + 居中偏移），所以改了尺寸之后点击位置依然准确

### 📡「网络」页：扫描到几条就列几条

- 原来会把**同名接入点合并**成一条 —— 扫描到 9 条记录、5 个不同名字，页面只画 5 行，看起来像「剩下的藏起来了」
- 同一个名字出现在 3 个信道上，就是 3 个可以连的接入点，行里本来就写着信道
- 「网络」页一打开就自己扫描（按钮留着重扫），不用先点一下

### 🔧「控制」页：一块永远在加载的空白

- 「屏幕」卡片一直画着骨架屏：`/api/display` 这条路由写成了 `HTTP_GET | HTTP_POST`，而在 ESP-IDF 里 `httpd_method_t` 是**枚举**不是位掩码（`1|3 = 3 = HTTP_POST`），于是只匹配 POST；页面用 GET 去读屏幕状态，永远拿到 405
- 现在卡片里是开关与亮度滑杆

### 🗄️「服务器」页：可以改了

- 每一行多了**铅笔**：改地址 / 账号 / 密码，**密码留空就是不动它**
- 同一地址再存一次从此是**原地替换** —— 端口和密码都保留，不再往文件里堆第二份

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.2.2-20261012.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAC0000`，你的 **Wi-Fi 密码、音乐设置和配好的服务器列表都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB
