## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.1.1-20261010.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAC0000`，你的 **Wi-Fi 密码和音乐设置不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

## 🏷️ 版本号怎么读

`v` **0** `.` **1** `.` **1** `-` **20261010**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `1` | 功能版本 | 加了新功能 |
| `1` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261010` | 构建日期 | 这一版固件是哪天编译的 |

这一版没有固件功能改动（就是文档 + 发布流程），所以只动了第三位 🫶
