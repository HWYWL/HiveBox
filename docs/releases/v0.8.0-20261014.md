# 🍊 HiveBox 固件更新啦！`v0.8.0-20261014`

这一版把那块板子**真的接到了服务器上** 🖥

以前「服务器监控」只能**看** —— 硬盘满了、容器挂了、某个服务不在了，想动手还是得去开电脑、开一个终端、`ssh` 进去。而这块板子就摆在旁边，本来就是为了**不用开电脑**。

现在监控页右上多了一个**「终端」按钮**：点一下，**就在那台机器上敲命令** ⌨️ 是真的登录 shell —— `cd` 记得住、颜色是彩的、进度条会动。

顺带把输入光标改成了**一条会闪的竖线** ✏️ 以前那个 9 px 的方块，看着像在选字，不像在打字。

## ✨ 这次更新了什么

### 🖥 监控页多了一个「终端」按钮

- 进**「服务器监控」** → 打开一台机器，看页头那一行：`概览` / `硬盘` 两个标签的**右边**，多了一个**带图标 + 文字的「终端」按钮** ✅
- 点下去**直接跳到终端应用**，而且**已经连上那台机器** —— 不是「先跳过去、再等它连」，而是**切屏之前会话就已经要好了**：你看到的第一帧就是那台机器的画面 🎬
- 开在哪个位置也说得清楚：页头那一排本来就是「对这台机器能做的事」，而终端是**整台机器的能力**，不是「硬盘」那一页的能力 🔧（原来页头那支**编辑铅笔从这里撤了** —— 改机器这件事已经在列表行上，不用先进一个「凭据可能正好是错的那台机器」的会话）
- 落点走的是启动器自己「打开第几个应用」那条老路，所以**状态栏那排图标、应用切换顺序、尺寸交接**全都照旧，没有第二套逻辑 ✅

### 🔐 是真终端，不是「一条一条跑命令」

- 板子向服务器要的是一个**伪终端（PTY）**，报的终端类型是 `xterm-256color` —— 也就是**服务器那边真的起了一个登录 shell**，不是板子在假装 🐚
- 所以 **`cd /volume1` 敲一次，下一条命令就还在那个目录里** ✅ `export`、管道、`&&`、`$(...)` 都成立 —— 这是「终端」和「远程执行」的分界线
- **提示符是服务器自己画的**（`user@host:cwd$`），不是板子画的。板子画的是四周那一圈框 🖼
- **颜色是真的**：`ls` 把目录染蓝、`git status` 把改动染绿 —— 用的是 VS Code 终端那套 16 色，256 色和真彩色（`SGR 2;r;g;b`）也认 🎨
- **`docker pull` 那种进度条也会动**：回车（`\r`）会回到行首**重画**，而不是刷出一屏来 —— 这一条是这个版子里最费工夫的地方之一 ⏳
- 终端那个铃声（`\a`）**故意不响**：板子有喇叭，但终端响铃是另一回事 🔕

### ⚡ 会话是保持的，而且和监控**各走一条连接**

- 上一次更新里「服务器监控」**每次采样都重新登录一次** —— 这一点**没有变**，那是监控该有的样子（保持的连接会死在 NAS 重启、路由器掐闲置、服务器自己的 idle 超时上，而这三种失败**都是静默的**）
- 终端用的是**另一条连接**：登录一次，一直用 🔗 两条连接互不打扰，所以**你在这儿敲命令的时候，旁边那页的监控数字照常在跳** 📊
- 这意味着多了一份状态和**一条 32 KB 的 PSRAM 线程** —— 而且它**是第一次打开终端时才起的**，没开过终端的板子不为它付这笔钱 💾

### 🚦 出事了会告诉你，不会一声不吭

- 页面底下多了一行**状态行**，**只在有事的时候出现**：
  - `Logging in to alice@nas.local…` —— 正在登录（灰字，等着就行）
  - `The session on nas.local ended.` —— 你在机器上敲了 `exit`（灰字）
  - **红字**说出是哪一种错 ❌：`…did not answer.`（不响应）/ `…would not take the account.`（账号被拒）/ `…is not the machine this board was told to expect.`（主机密钥变了）/ `There is no network to reach it on.`（没网）/ `…could not agree on how to speak.`（协议谈不拢）/ `This board has no SSH client…`（这套构件里没编 SSH）
- 红字下面跟着两个按钮：**`Reconnect`**（重连一次）和 **`Leave`**（回板子自己的本地 shell）
- **会话好好的时候，这行一个字都不显示** —— 页面是那台机器的，板子不该拿自己的话去挡着它 🤫
- `Leave` 是**告诉机器**再见，不是「自己不管了」：对面那个是一个登录，扔在服务器上等到超时，就是**别人的进程** 🚪

### ✏️ 光标：从方块变成一条竖线，而且会闪

- 以前那个光标是 **9 px 的方块**（差不多一整个字宽），现在是一条 **2 px 的竖线**，高度是字号减 2 px、往下挪 3 px 对齐基线 —— 就是你在电脑上看到的那种插入符 ✏️
- 它会**闪**：亮 **500 ms**、灭 **500 ms** —— 和 iced 自带文本框的光标同频，同一页上两个光标不会闪成两种快慢 🕐
- 灭的那一半**不是「不画」，而是「画成透明的」**：不画的话那一行的宽度会跟着抖一下；透明就不会 ✅
- 闪的节拍是**按帧携带的时间**算的，不是数帧数。桌面窗口 60 fps、板子上一轮循环一帧，**数帧数会让闪烁快慢跟着屏幕跑**；按时间算才是真的半秒 ⏱

### ⌨️ 键盘还是那块共享的软键盘

- `-` `/` `:` `_` `|` `~` `$` 一个不缺（数字页、符号页上都有），只是敲 `docker ps -a` 要点二十几下 🫠
- 输入是**一行一行发出去的**（按回车才发 `\r`），不是按一个键发一个字 —— 因为对面的 shell 自己会回显、自己会重画，这样**回显和输出永远是同一个顺序** ✅
- 还有个小地方：窗口中途被改了大小，**这一条会话的列宽不会变**（协议里没有「我现在多宽了」这条话），要新列宽就 `Reconnect` 一次 🔁

### 🚫 有两件事做不到，先说清楚

- **全屏程序用不了**：`vi` / `vim` / `top` / `htop` / 独占屏幕的 `less`。它们靠「把光标挪到第 10 行第 20 列」来画界面，而那一套**只有等宽字体才立得住** —— 板子的界面用的是**比例字体**
- 硬撑的结果是把 `vi` 的光标挪到一个**和它自己画的字不在同一处**的地方，比不画更糟 🫠 所以**光标定位指令被丢掉了**，认不出来的转义**原样忽略**，而不是画错
- 能用的是「看一眼、查一条、跑一条」这一类：`ls`、`df -h`、`docker ps`、`docker logs`、`cat`、`git status`、`systemctl status`、`uname -a` ✅
- **软键盘上没有 `Ctrl`、`Tab`、`Esc`、方向键**（也没有 `↑` 翻历史）。所以 **Tab 补全、`Ctrl+C` 打断**这两件最顺手的事没有 —— 一条停不下来的命令，出口是按 **`Leave`** 把会话挂掉 🛑（历史命令还是有的：`↑` 没有，但你敲过的都在上面那**120 行**里）
- **回滚留 120 行**：一屏之外更早的东西会被顶掉。`cat` 一个超大文件、`journalctl` 拉一把日志，前面就冲掉了 📜

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.8.0-20261014.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAF0000`，而数据分区从 `0xB00000` 才开始 —— 你的 **Wi-Fi 密码、服务器地址与账号、音乐设置和文件都不会丢** 🎵
- ✅ **你配好的服务器也都还在**：这一版是**在它上面多开一个终端**，不是改它被存在哪
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB
