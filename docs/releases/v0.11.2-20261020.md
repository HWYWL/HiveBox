# 🩹 v0.11.2｜三个「怎么变成这样了」，都修了 🔧

> 一句话：**商店的图标方回来了，天气的温湿度会动了，服务器又有了列表、详情和终端。**
> ⚠️ 这一版要**刷固件**：包用上了一条新的宿主服务（ABI 1.5）。

---

## 🔲 商店里的图标为什么是长条

不是图标坏了，是**那个方块被拉长了**。`iced` 里 `center_x(填满)` 设的不只是对齐 —— 它把
**宽度**也一起改成了「填满」，于是刚设好的 `40×40` 被覆盖掉，方块摊成了 160 宽的条子，里面的
字形跟着被摊平。改成 `center_x(固定 40)` 就好了：现在它是四四方方的，跟桌面磁贴一样。

## 🌡️ 天气的温湿度、风速为什么一直是 0

Open-Meteo 的回答里，`current_units` 就在 `current` 前面，而且**键名一模一样** —— 只是值是
`"°C"`、`"%"`、`"km/h"` 这些单位。原来在整份文档里找第一个 `temperature_2m`，找到的正是那个
单位，读出来不是数字，于是落到默认值 0。现在先定位到 `"current":{ … }` 那一段再读，三行数字
（温度、湿度、风速）就都是真的了。

## 🖥️ 服务器：列表 / 详情 / 终端，三页回来了

之前只剩一页「当前那台的读数」，因为**应用拿不到「有哪几台机器」**——快照只有一份，而配置在
板子自己的 `/internal/AppData/NAS/nas.conf` 里。

这一版给 ABI 加了一条服务：`hb_nas_devices`，把板子读过的那份配置里的 `host` 与 `user` 递出来
（**密码不过边界**）。于是：

- **列表页**：抬头写「N 台服务器」，一行一台（地址、账号 · 在线或未读取、右端一个状态点），
  右上角「添加」，点一行进详情。
- **详情页**：抬头是这一台的地址，下面一条细线，右上角 **「终端」**；六个格子 —— CPU 与温度、
  内存、网络、磁盘读写、存储、磁盘繁忙；右边一颗「重读」，底部写明读数是多少秒前的。
- **终端页**：真的开一个会话（`hb_nas_shell_open`），输出区滚到最新一行，底部四个快捷命令
  `ls` / `df -h` / `uptime` / `free -h`，右上角「断开」。

「添加」现在还不是表单：**添加 / 编辑 / 删除落在 设置 → 服务器 里**（那儿的表单在固件里，
写的是同一份文件），列表页会直接告诉你这句话，而不是给一个按下去没反应的按钮。

## 📦 怎么更新

1. **先刷固件**（ABI 1.4 → **1.5**，合并镜像写 `0x0`），或是在 设置 → 系统更新 里装这一版
2. 然后打开**应用商店 → 更新**，十二个包会显示 `v0.2.1`，一次装完

只刷固件不更新包的话：新固件跑旧包没问题；但**旧固件装不上** `v0.2.1` 的服务器包 —— 它要求的
那条新服务旧固件没有。
