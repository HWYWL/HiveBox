## ✨ 这次更新了什么

### 🌤 新应用「天气」：你在哪，天气就是哪的

- 打开就先**按 IP 定位**（不用填任何东西，标题栏写着定位到的城市名），再去取**当地**的预报：一屏三段 —— **现在**（温度、天气、湿度、风速）、**未来几天**（今天 / 明天 + 后面三天，最高最低）。两个服务都不要账号、不要密钥
- 上一版这里写死了北京：一块插在广州的板子，报的是北京的天。**现在的地名是问出来的，不是一个常量**
- 打开应用时会先发起请求，然后画面每秒自己看一眼答案到了没有 —— 「正在获取…」是这一页的正常状态之一，不是卡住了
- **每一种失败都说清是哪一种**：没有连接到网络 / 时钟还没有校准 / 没有服务器回应 / 请求超时 / 安全连接失败 / 返回内容超出上限，各自配一句该怎么办（「请在设置里打开 Wi-Fi」「先校准时间，再试一次」）。报一句「加载失败」等于把排查的活儿推给了看屏幕的人

### 🎮 新应用「游戏」：一个磁贴，一张游戏列表

- 第一款（也是现在唯一一款）是 **2048**：滑动合并数字，拼出 2048 还能接着玩，分数、胜负、重开都在同一页。屏幕下方就是四个方向键 —— 触屏没有键盘可以借，游戏就得把方向键画出来
- 每一局用**板子的开机时长**当种子，所以每次打开都是新的一局：菜单上写「用下面的方向键滑动」，而开出来的是同一个棋盘的话，这句话就是在骗人
- 它是这个桌面唯一一个**不是读数**的磁贴。留一个游戏的位子，是因为这块屏幕一直摆在有人坐着的房间里

### 📡 新应用「信道地图」：2.4 GHz 哪个信道值得用

- 十三个信道画成一张**压力图**，给出一条**建议信道**。算法不是「数一数每个信道有几条网络」，而是**每条网络按 20 MHz 掩码摊到相邻的五六个信道上、再按信号强度加权** —— 2.4 GHz 的信道只隔 5 MHz，一条网络是同时被四五个信道听见的；只数精确匹配，会让「旁边有一条大嗓门」的信道看起来是空的，而那正是让人搬错家的那个判断
- 建议在 **1、6、11** 里挑互不重叠的那条，而不是全图最空的那条：楼里安静时随便哪个信道都行，楼里拥挤时，一条和谁都重叠的信道比一条看着忙但不重叠的信道更糟
- 下面还有一张**信号分布图**（-40 到 -100 dBm，每行 10 dBm）和网络列表。**5 GHz 的网络照列不误，但不进算术** —— 信道 37 上的一条网络，占不了信道 1 的一点地方，把它算进去只会让这一页对真实存在的噪音说得更小声
- 扫描是**异步**的：打开页面问一次、按「重新扫描」再问一次，扫描的那两秒里页面照常画（写着「正在扫描…」）。一次扫描是驱动好几秒的时间，等它就是把整页停下来

### 🌐 板子学会了「自己上网」：HTTP 客户端 + 自动对时

- `pomelo-hal` 新增**第十个后端 `HttpBackend`**：`start` → 轮询 `state` → `take_result` 三步，和 Wi-Fi 扫描同一个形状。请求是一次阻塞的 socket + TLS 握手，所以它跑在**自己的任务**里（自己的栈），界面永远不会被一条网络请求停住；同一时刻只允许一条请求在飞，第二条拿到的是「忙」而不是悄悄插队
- **SNTP 对时**：连上 Wi-Fi、拿到 IP 的那一刻开始对时，时间落进**硬件 RTC**（`board_rtc.c` 一直拦着 `settimeofday`，所以断电再开也还在）
- 这里有个前提值得知道：**HTTPS 证书的有效期是拿系统时钟比的**，一块从没对过时的板子（时钟停在 1970）握手必然失败 —— 而它看起来和断网一模一样。这一种失败被单独拎出来叫**「时钟还没有校准」**，天气页会直接告诉你「先校准时间，再试一次」，而不是让人去查 Wi-Fi
- 响应体上限 16 KB（与 TLS 的内容缓冲区同宽），太大是一种**明确**的失败，不是读到一半崩掉

### 🔋 三个页面的右侧方角修好了

- **电量日志、概览、信道地图**右边的圆角不见了、还一直顶到屏幕边缘：原因是 iced 的滚动条**画在内容上面**（浮动滚动条不占布局），那条轨道正好压住每张卡片最右侧约 10 像素，把圆角切成了方角。三页都改成**不画滚动条**（终端、设置、音乐播放器一直如此），卡片恢复满宽 + 两侧圆角；信道图第 13 信道和「20 MHz 重叠模型」的标注也完整了
- 面板有手指、没有指针，一根头发宽的滚动条是拿来看的、不是拿来抓的

### 🛠 天气点开就死机重启，是两个真 bug 撞在一起

- C 侧 HTTP 客户端在「连接打不开」的分支里把同一块内存**释放了两遍**，堆被写坏之后跳到野函数指针 —— 串口里那句 `Guru Meditation InstructionFetchError` 就是它。**重复的那次释放删掉了**
- 同时 HTTPS 握手会向**内部 SRAM** 要缓冲区，而那里只剩约 33 KB（报 `MBEDTLS_ERR_SSL_ALLOC_FAILED`）。现在 TLS 的缓冲区改从 **8 MB 的 PSRAM** 拿
- 真机上连着开合天气两次、再开关五个应用，没有再重启 ✅

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.4.0-20261013.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xC10000`，你的 **Wi-Fi 密码、音乐设置和配好的服务器列表都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB
