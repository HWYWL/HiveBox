# 🍊 HiveBox 固件更新啦！

> **版本**：`v0.11.0-20261016`　**芯片**：ESP32-S3　**合并镜像**：`HiveBox-v0.11.0-20261016.bin`（5.77 MiB / 写入偏移 `0x0`）

这一版把**「板子自己装字体」**接通了：更新页的「**字库**」那一行点一次「**安装**」，板子自己把**字体**和它的**字形表**两个文件都下到 SD 卡上，重启就用上 —— 不用在电脑上下好、再拷进卡里了。📥

顺带修掉了一个一直在骗人的「可更新到 v1」。

---

## 📥 一个字：点「安装」就行

字库这一行背后是**两个文件**（字体 1.91 MB + 它的表 2.27 MB，一共约 4.2 MB），点一次「安装」全下来：

- **先字体、后表**：表是开机扫的那一件 —— 它是把这一对变成字体的那一下 🔑
- **进度条会走两轮**：换文件的时候进度会从头开始。那不是重试，是第二件东西在下了 ⏳
- **中途断了也不怕**：拔电、按「取消」、第二件没下来 —— 卡上都不会留下一对错的。先落下的那份字体没有表就什么都不是，开机照旧用原来那份；再点一次「安装」就好 🛟
- 装完提示「**字库已更新到 v3，重启后生效**」，**重启**才读卡上的字体 🔁

## 🧾 清单里的「字库」现在可以是一对

以前「字库」这一项只能是一个文件，现在它可以带**另一半**：

```json
"font": {
  "version": "v3",
  "file": "hivebox-font-24px-v3.bin",   ← 字形表
  "size": 2268084, "sha256": "…",
  "face": {                              ← 烘出这张表的那份字体
    "file": "hivebox-face-v3.otf",
    "size": 1910512, "sha256": "…"
  }
}
```

一个字形表只对**烘它的那份字体**有意义（表里存的是字形的编号）。所以想换字体，必须两件一起换 —— 这也正是为什么以前那个「只有一个文件」的形状装不出更多字 📐

## 🧹 顺手修掉那个假的「可更新到 v1」

之前清单里发的那个「字库」，是**照镜像内置字体**烘出来的表 —— 它和镜像里已经带着的那张**一个字节都不差**。装它什么都不会变，而更新页会一直指着它喊「可更新到 v1」。

**把卡上的字体删掉之后看到的就是它**：那一行比的是卡上有什么，卡上空的，于是它把镜像自带的那张表当成更新报了出来 🫠

现在不发它了。字库这一项发的就是 v3 那一对；卡上已经装着 v3 的时候，那一行只说「已装 v3」，不再提 v1。

## 🚧 还没有的东西（先说清楚）

- 「**固件**」那一行**还是不能从板子上装**：往另一个分区写镜像这件事没接通，点下去还是「**这一步还没接通**」🚧 刷机照旧（见下）
- 字体是**重启后**生效的，没有热加载
- 板子上没插卡、「字库」那一行会说得明明白白，而不是假装能装

## 📦 怎么刷

```bash
esptool.py --chip esp32s3 -p <你的串口> write_flash 0x0 HiveBox-v0.11.0-20261016.bin
```

**分区表没动**，所以 Wi-Fi 密码、文件、服务器列表、卡上的字体包都还在。刷完进「更新」点「检查」，就能看到这一版的字库那一行了。

## 🏷 版本号怎么读

`v0.11.0-20261016`：`0` 大版本（第一位数）、`11` 这一版加了多少东西（第二位数）、`0` 修了多少问题（第三位数）、`20261016` 编译日期。
**这次动了第二位** —— 板子上的应用多了一件能做到的事，不是小修小补。

## 🍊 刷完可以看看这几处

- 进「**更新**」→ 点「**检查**」：「**字库**」那一行会指出 **v3** 👀
- 点「**安装**」：进度条走两轮（字体 → 表），然后提示已更新到 v3 📥
- 顺手翻一眼 SD 卡的 `fonts/`：里面躺着**两个**文件，一个是字体、一个是它的表 🗂
- **重启**，再进「**更新**」→「**检查**」：那一行变成「**已装 v3**」，没有可更新的了 ✅
- 进「**文件**」翻翻中文名：字齐了 —— 生僻字、网络名、服务器名都画得出来 🈶
- 「**固件**」那一行按「安装」：仍然是「这一步还没接通」🚧
