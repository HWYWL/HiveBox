# 🍊 HiveBox 固件更新啦！

> **版本**：`v0.10.3-20261016`　**芯片**：ESP32-S3　**合并镜像**：`hivebox-firmware-v0.10.3-20261016.bin`（5.78 MiB / 写入偏移 `0x0`）

这一版改的是**怎么找到东西**：桌面上两个磁贴换了名字（原来的名字放不下，一直在屏幕上被截成「任务查…」和「服务器…」），**「服务器」和「文件管理」搬到了第一页**，设置页那张「固件版本」的读数也不再画到卡片外面。🔤

**这一版不用插线** —— 更新页里点一次就行。👇

---

## 📛 两个磁贴换了名字：名字只有四个汉字的位置

桌面上一个磁贴的名字是**一行**，放不下就干脆截断加省略号（这是给「Web Manager」这种长英文名准备的规矩）。一页改成四列之后，一个磁贴只剩 **105 px** 宽：

- **四个汉字是 96 px** —— 放得下 ✅
- **五个汉字是 120 px** —— 放不下，「任务查看器」和「服务器监控」就是这么一直在屏幕上画成「任务查…」和「服务器…」的 👀

以前一页三列、一格 144 px，宽得能藏住第五个字，所以没人看出来；四列之后就藏不住了。现在改成：

| 原来 | 现在 |
| :--- | :--- |
| 任务查看器 | **任务详情** |
| 服务器监控 | **服务器** |

「服务器」这一页自己的标题也跟着改了 —— 磁贴上的名字和页里的标题本来就该是同一个。

## 🗂 「服务器」和「文件管理」在第一页

第一页现在收在这三张上：**任务详情**（它在跑什么）、**服务器**（旁边那台机器）、**文件管理**（这两边的存储）—— 都是关于**这台盒子本身**的。

一页八个位置装不下九个想上第一页的应用，让位的是**计算器**：它是这一屏上唯一一个和盒子无关的应用（一个碰巧跑在这儿的 app），也是以前一页六个位置时排在末位的那一张。它现在开第二页。

分页点还是**两个**：第一页八个，第二页七个，没有多也没有少。

## 📐 设置页的「固件版本」不再被挤出卡片

那张卡片原来按**两行**算高度（名字一行、值一行，88 px）。而版本号是一串**没有空格**的字符 —— `v0.10.3-20261016` 十六个字符约 **197 px**，一行只有 **176 px**，所以它一直要换行：

- 换出来的第二行塞不进按两行算的卡片，多出来的高度从上下两边挤出去
- 上半截把「固件版本」几个字顶到卡片上沿，下半截把 `16` 画在卡片下边缘**外面** 🚫

卡片现在按**三行**算（118 px）。「芯片型号」那张留着第三行空着 —— 两张一样高才是一排卡片，空着的那一行是它该付的代价。

## 📦 怎么刷

**这一版不用数据线**：bootloader 和分区表都没动，直接在板子上刷就行 ——「**更新**」→「**检查**」→「**安装**」→「**立即重启**」。刷完 Wi-Fi 密码、文件、服务器列表、SD 卡上的字体包都还在。

想用数据线刷，或者从更老的版本过来，也可以：

```bash
esptool.py --chip esp32s3 -p <你的串口> write_flash 0x0 hivebox-firmware-v0.10.3-20261016.bin
```

## 🏷 版本号怎么读

`v0.10.3-20261016`：`0` 大版本（第一位数）、`10` 这一版加了多少东西（第二位数）、`3` 修了多少问题（第三位数）、`20261016` 编译日期。
**这次动的是第三位** —— 没有新开一页、没有加磁贴，换的是名字与所在页，再修好一处画到卡片外面的读数。

## 🍊 刷完可以看看这几处

- 桌面上：「**服务器**」和「**文件管理**」都在**第一页**了，名字是一整行的，没有省略号 👀
- 往左滑一页：「**计算器**」在第二页开头 🔢
- 进「**设置**」：最上面那张「固件版本」的卡片，版本号完整地躺在卡片里 ✅
