# 🍊 HiveBox 固件更新啦！`v0.2.1-20261012`

这一版不长，但**打开盒子就能看见** 👀

先说重点：**桌面背景换成纯黑，图标换成饱满的色块** —— 屏幕不再把黑边框的边线画在自己身上，而每个应用一眼就能认出来。

---

## ✨ 这次更新了什么

### 🌑 背景：纯黑

- 这块屏幕装在一个黑色边框里，原来那层「近黑的蓝」只比黑浅一点点，反而**把边框的边线画在了屏幕上** —— 屏幕圆角处尤其明显
- 现在底色是**纯黑**，边框和屏幕连成一片，屏幕上只剩磁贴和状态栏本身
- 任务查看器、网页管理、音乐播放器、服务器监控的页面底色一起换成同一片纯黑（终端、设置、计算器本来就是黑的）

### 🎨 图标：饱和色块 + 白色字形

- 磁贴原来是**近黑**的方块 —— 强调色暗到磁贴和它背后的壁纸在手臂距离上看成同一片
- 现在每个应用一个饱和色、按色相分开，不读字也认得出：
  - 音乐 **玫红** ｜ 网页管理 **蓝** ｜ 终端 **绿** ｜ 设置 **灰**（和手机一样，设置是灰的）
  - 计算器 **琥珀** ｜ 任务查看器 **青** ｜ 服务器监控 **紫**
- 白色字形不变，压在饱和色上比压在近黑上更清楚
- **按下态**跟着改：原来是把颜色 ×1.35，饱和色一乘就每个通道顶到 255、闪成灰；现在改成混入 16% 的白，永不溢出

### 🔧 顺带

- 设置 → 主题页的「壁纸」一行不再自称 `macOS Sierra`，照实写成纯黑
- 未点亮的翻页点在纯黑上提亮一档

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.2.1-20261012.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xAC0000`，你的 **Wi-Fi 密码、音乐设置和配好的服务器列表都不会丢** 🎵
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB
