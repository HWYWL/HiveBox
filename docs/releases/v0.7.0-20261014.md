# 🍊 HiveBox 固件更新啦！`v0.7.0-20261014`

这一版修的是**「服务器监控」里那两处按不顺手的地方** 🛠

设备列表每一行现在带着**「编辑」和「删除」两个正经按钮** —— 原来那两个小图标，形状多大点击区就多大，手指压上去有一半靠自己瞄 🎯 表单里的输入框也不再被右边缘那条滚动条切掉，右侧的边框和圆角都回来了。

顺手把删除这件事**变安全了**：点「删除」不再当场删，而是先问一句「确定删除 192.168.1.10 吗？」—— 你要删的那台机器，会**留在屏幕上**让你核对 🔍

---

## ✨ 这次更新了什么

### 🔘 「编辑」「删除」终于按得准了

- 原来这两个动作是**两个小图标**（铅笔、垃圾桶），**字形多大、点击区就多大** —— 手指按上去，压不压得中要看运气 🫠
- 现在它们是**文字按钮**：**「编辑」**和**「删除」**，一边一个排在每行右边。一个按钮约 **59 × 32 px**（字 17 px，左右各留 12 px、上下各留 7 px）—— 不再是「瞄准」，而是「按一下」 ✅
- 按下去会**填充底色、文字反过来**（编辑用原来的字色、删除用红色），按没按到一眼就看得见
- 列表那一行同时从「一个大按钮」拆成**三个各管一段的按钮**：左边那块点进监控页，右边两个分别是编辑和删除。按钮套按钮的时候，一次点击归谁要看平台先走到哪一个 —— 这种事不该交给运气

### ✏️ 每一行都能直接编辑

- 点某一行的**「编辑」**，直接打开**那台机器**的表单，地址、账号、密码已经填好 —— 不用再点进监控页、再从右上角找那支铅笔了
- 保存的规矩没变：**同一地址再存一次是更正，不是新增** ✅

### 🗑 删除前先问一句

- 点**「删除」不会马上删**。列表底部原来放「添加设备」的位置会换成一排确认：
  `确定删除 192.168.1.10 ？` + **「取消」** + 红底的 **「删除」**
- 为什么要先问：这一行是放在一张**用拇指滑动的列表**上的，一次没按准的滑动就可能删掉它；而被删掉的是一个地址、一个账号和一个**没有第二份的密码** —— 这件事不能收回
- 问句出现的时候，**要删的那台机器仍然留在屏幕上**：问句里的那个地址，正是拿来和它对一眼的东西 👀
- **「取消」是一个画出来的按钮**，而不是「点别处就算取消」—— 这一页的「别处」是另一个设备行，而那一行本身也是个按钮

### 🎯 还有个更细的地方：这个问句记的是「地址」，不是「第几行」

- 列表是会变的：你在表单里删掉一台机器，下面每一行都会**往上挪一格**
- 如果问句记的是行号，挪完之后**被删掉的就是另一台机器了** 🫠
- 所以它记的是**那台机器的地址**。有一条单测专门盯着这件事：先问第二台，再从表单删掉第一台，最后确认 —— 走掉的必须是第二台 ✅

### 📐 输入框不再「超出边界」

- 表单里那三个输入框是**整页宽**的，而 iced 的滚动条是**浮在内容上面**画的（不占布局）—— 那条导轨正好压住输入框**最右边约 10 px**：边框和圆角被一条页面自己颜色的竖条盖住，看起来就像框子**跑出了屏幕** 📏
- 现在这一块的滚动条**不画了**（**拖动照旧有效**，只是没有那条提示）。输入框恢复满宽 + 两侧都有圆角 ✅
- 代价说清楚：**少了「下面还有内容」那一点提示**。三个字段比键盘上方那点空间高，所以第三个（密码）要**往上拖一下**才看得全 —— 这一点改之前也是这样，改的只是**拖的时候不再牺牲框子的右边缘**

## 📦 怎么刷（30 秒搞定）

```bash
pip install esptool
esptool --chip esp32s3 --port COM3 --baud 921600 write_flash 0x0 hivebox-firmware-v0.7.0-20261014.bin
```

- ✅ **合并镜像**，写到 `0x0` 就行，不用管偏移
- ✅ 只覆盖 `0x0`–`0xABFF00`，而数据分区从 `0xB00000` 才开始 —— 你的 **Wi-Fi 密码、音乐设置和文件都不会丢** 🎵
- ✅ **你配好的服务器也不会丢**：这一版改的是它**怎么被编辑**，不是它**被存在哪**
- ✅ 想恢复出厂：先 `erase_flash`，再刷一次
- 💡 `--port` 换成自己的串口：Windows `COM3` 这类，Linux `/dev/ttyACM0`，macOS `/dev/tty.usbmodem*`
- 💡 连不上就按住 **BOOT** 键再插 USB

## 🏷️ 版本号怎么读

`v` **0** `.` **7** `.` **0** `-` **20261014**

| | | |
| :--- | :--- | :--- |
| `0` | 大版本 | 重大更新才动，**慎之又慎** ⚠️ |
| `7` | 功能版本 | 加了新功能 |
| `0` | 修复版本 | 修 bug / 补漏洞 / 优化代码与文档 |
| `20261014` | 构建日期 | 这一版固件是哪一天编译的 |

这一版**板子上的应用变了** —— 设备列表多了「**每一行都能编辑**、**每一行都能删（而且要先确认）**」这两件事，是功能版本，所以动的是第二位，第三位归零 🫶（输入框那条算修复，跟着这一版一起交出去。）
